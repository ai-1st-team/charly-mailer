# CHARLY MAILER Overview

## Что это

CHARLY MAILER — desktop-приложение для управления email-рассылками.

## Стек

- Python 3.11+
- CustomTkinter для GUI
- requests для HTTP
- python-dotenv для переменных окружения
- stdlib: csv, json, re, threading, logging

## Текущий статус

Готов каркас проекта, блок прокси, блок SMTP, загрузка тем/тел/ссылок/имён отправителей, база получателей, control-инжект, CC/BCC, пресеты кампании, вкладка статистики и вкладка отправки.

При запуске `python main.py` открывается тёмное окно `CHARLY MAILER` размером 900x600 с вкладками:

- Setup
- Content
- Campaign
- Send
- Stats

Вкладка `Setup` содержит:

- блок `Прокси`: загрузка из файла, загрузка по URL, автообновление URL-списка, список прокси со статусами и проверка всех прокси
- блок `SMTP`: загрузка `smtps.txt`, карточки аккаунтов, проверка одного/всех, статусы, счётчик отправленных за сессию

Вкладка `Content` содержит:

- блок `Темы писем`: загрузка `subjects.txt`, счётчик, превью первых 5 строк и тестовую подстановку `{{name}}`, `{{email}}`, `{{senderName}}`
- блок `Имена отправителей`: загрузка `senders.txt`, счётчик, превью первых 5 имён и режим `только email без имени`
- блок `Ссылки`: загрузка `links.txt`, `links1.txt`, `links2.txt`, счётчики списков и настройка уникальности ссылок в одном письме
- блок `Тела писем`: загрузка `bodies.txt`, разделитель `===END===`, вложенный спинтакс, plain/html detection и большое поле предпросмотра

Вкладка `Stats` содержит:

- прогресс-бар текущей кампании
- глобальные метрики
- таблицу SMTP-аккаунтов
- таблицу прокси
- экспорт дневного лога в JSON/CSV

Вкладка `Send` содержит:

- тестовую отправку на один email
- preview полностью собранного письма
- кнопки старт/стоп/пауза
- настройки скорости и случайного разброса задержки
- восстановление незавершённой очереди из `data/queue-state.json`

Вкладка `Campaign` содержит:

- загрузку CSV базы получателей
- счётчик получателей
- preview первых 5 строк `email/name`
- настройку control-инжекта каждые N писем
- поле контрольных адресов через запятую
- блок `Дополнительные получатели`: CC/BCC адреса и проценты применения
- блок `Пресеты кампании`: сохранить/загрузить JSON-пресет из `data/presets/`

Для проверки SMTP без GUI есть `test_smtp_login.py`.

README содержит актуальную инструкцию запуска для Windows/macOS/Linux, включая запуск через `start.bat`, `start.command`, ручной запуск и диагностику окружения.

## Что дальше

Следующая задача должна наполнить одну из существующих вкладок или core-модулей. Новые вкладки не добавляем.

Для будущего старта рассылки важно:

- прокси: использовать `ProxyManager.prepare_live_rotation()`
- SMTP: использовать `SMTPManager.prepare_live_rotation()` и `get_next_live_account()`
- темы: использовать `SubjectManager.render_random(recipient, sender_name)` для каждого письма
- тела: использовать `BodyManager.render_random(recipient, sender_name)` для каждого письма
- имена отправителей: использовать `AppState.choose_sender_name()`; если `from_email_only=True`, From содержит только SMTP email
- ссылки: создавать один `LinkRenderContext` на письмо и передавать его в рендер темы и тела
- статистика: использовать `get_stats_manager().start_campaign()` и `record_delivery()`
- база получателей: `Campaign` записывает recipients в `get_app_state().set_recipients(...)`
- control: `Campaign` записывает `control_every` и `control_recipients` в `AppState`
- CC/BCC: `Campaign` записывает адреса и проценты в `AppState`, `EmailComposer` решает применение на каждое письмо
- пресеты: `core.presets` сохраняет пути к файлам и настройки; при загрузке чистит runtime и перечитывает файлы
