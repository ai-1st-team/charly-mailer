# Task 05 — Bodies

## Сделано

Добавлена загрузка тел писем из `bodies.txt`.

Формат:

- одно тело может занимать несколько строк
- тела разделяются строкой `===END===`
- пустые тела после разделения игнорируются

## Генерация письма

Порядок рендера тела:

1. выбирается случайное тело
2. разворачивается спинтакс
3. подставляются плейсхолдеры
4. определяется формат `plain` или `html`

Плейсхолдеры:

- `{{name}}`
- `{{email}}`
- `{{senderName}}`

## Спинтакс

Поддерживается любая глубина вложенности:

```text
{внешний {вложенный_a|вложенный_b}|другой вариант}
```

Реализация: рекурсивный AST-парсер в `core/content.py`.

Обычные фигурные скобки без `|` на текущем уровне считаются текстом. Это снижает риск поломки HTML/CSS.

## HTML/plain

Формат тела определяется автоматически по наличию HTML-тегов после рендера.

- если HTML-теги есть → `html`
- иначе → `plain`

## GUI

На вкладке `Content` теперь две зоны:

- слева `Темы писем`
- справа `Тела писем`

В блоке `Тела писем`:

- кнопка `Загрузить тела`
- счётчик `загружено N тел`
- кнопка `Превью`
- кнопка `Обновить превью`
- большое поле `CTkTextbox` с развёрнутым письмом
- метка формата `plain/html`

Превью показывает:

- случайную тему, если темы загружены
- формат тела
- развёрнутое тело с плейсхолдерами из тестовых полей
