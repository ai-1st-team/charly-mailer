# Task 01 — Skeleton

## Сделано

Создан стартовый каркас проекта:

- `main.py`
- `gui/`
- `core/`
- `data/`
- `logs/`
- `memory/`
- `.env.example`
- `.gitignore`
- `requirements.txt`
- `README.md`

## GUI

`python main.py` открывает окно `CHARLY MAILER`:

- размер 900x600
- тёмная тема
- фон `#0a0a0a`
- акцент `#4ade80`
- пять вкладок: Setup, Content, Campaign, Send, Stats
- в каждой вкладке по центру серый `// TODO`

## Решения

- Финальный набор вкладок — ровно пять. Новые вкладки в следующих задачах не добавляем.
- Логи и приватные данные держим в `logs/` и `data/`; содержимое исключено из git, `.gitkeep` оставлен для сохранения структуры.
- `core/storage.py` выделен как общий будущий слой для чтения TXT/CSV, чтобы не дублировать парсинг в других модулях.

## Важно дальше

- GUI не должен зависать: долгие операции выносить в threads.
- Секреты и чувствительные параметры — только через `.env` или приватные файлы в `data/`.
- После каждой задачи обновлять `memory/00-overview.md` и соответствующую заметку в `memory/20-tasks/`.
