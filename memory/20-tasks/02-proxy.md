# Task 02 — Proxy Support

## Сделано

Добавлена поддержка прокси из двух источников:

- локальный TXT-файл
- HTTP/HTTPS URL со списком прокси

Поддерживаемые форматы строк:

- `http://host:port`
- `http://user:pass@host:port`
- `host:port:user:pass`

## GUI

На вкладке `Setup` добавлен блок `Прокси`:

- кнопка `Загрузить из файла`
- поле URL и кнопка `Загрузить по URL`
- переключатель автообновления URL-списка раз в N минут
- таблица прокси со статусом, IP и комментарием
- кнопка `Проверить все`

Долгие операции идут в background thread, GUI не должен зависать.

## Core

`core/proxy_manager.py`:

- парсит прокси
- нормализует строки в `ProxyRecord`
- маскирует пароль для GUI/logs
- загружает файл/URL
- заменяет прокси из того же источника при повторной загрузке
- проверяет прокси через `http://httpbin.org/ip`
- помечает мёртвые прокси как `dead`
- `prepare_live_rotation()` перед будущим стартом рассылки перепроверяет список и возвращает только живые прокси
- `get_next_live_proxy()` готовит round-robin ротацию

`core/storage.py`:

- `read_text_lines()`
- `parse_text_lines()`
- игнор пустых строк и строк, начинающихся с `#`
- fallback кодировок: `utf-8-sig`, `utf-8`, `cp1251`

## Логи

События загрузки и проверки пишутся JSON Lines по дням в `logs/YYYY-MM-DD.jsonl`.

## Важно дальше

Когда появится старт рассылки, перед отправкой вызвать `ProxyManager.prepare_live_rotation()` и брать прокси только через `get_next_live_proxy()` или `get_live_proxy_urls()`.
