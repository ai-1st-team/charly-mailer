# Task 06 — Link Macros

## Сделано

Добавлена поддержка макросов случайных ссылок в темах и телах писем.

Макросы:

- `[[LINK]]` → случайная ссылка из `links.txt`
- `[[LINK1]]` → случайная ссылка из `links1.txt`
- `[[LINK2]]` → случайная ссылка из `links2.txt`
- `[[LINK3]]` и далее по тому же правилу

## Логика

При формировании письма все link-макросы заменяются случайными ссылками из соответствующего списка.

Если макрос найден, но соответствующий файл не загружен, рендер падает с понятной ошибкой:

```text
Макрос [[LINK1]] найден, но файл links1.txt не загружен
```

В одном письме разные вхождения одного макроса могут получить разные или одинаковые ссылки.

Настройка:

- `уникальные ссылки в письме` выключена по умолчанию
- если включена, один и тот же список ссылок не повторяет ссылку внутри одного письма
- если уникальных ссылок не хватает, рендер возвращает ошибку

## GUI

На вкладке `Content` добавлен блок `Ссылки` под блоком тем:

- кнопка `Загрузить ссылки`
- диалог выбора нескольких файлов `links.txt`, `links1.txt`, `links2.txt` и т.д.
- список загруженных файлов со счётчиками
- чекбокс `уникальные ссылки в письме`

После загрузки видно строки вида:

```text
12 ссылок в links.txt  →  [[LINK]]
8 ссылок в links1.txt  →  [[LINK1]]
```

## Core

`core/content.py`:

- `LinkManager`
- `LinkRenderContext`
- `LinkLoadResult`
- `link_key_from_filename()`
- `link_macro_name()`
- `link_filename()`

`SubjectManager.render_random()` и `BodyManager.render_random()` теперь умеют принимать:

- `link_manager`
- `link_context`

Для одного письма нужно создавать один общий `LinkRenderContext` и передавать его в рендер темы и тела, чтобы настройка уникальности работала на всё письмо целиком.

## Важно дальше

Когда появится sender, порядок рендера одного письма:

1. создать `link_context = LinkManager.create_context(unique_per_message)`
2. с этим context отрендерить тему
3. с этим же context отрендерить тело
