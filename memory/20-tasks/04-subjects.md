# Task 04 — Subjects

## Сделано

Добавлена загрузка тем писем из `subjects.txt`.

Формат:

- одна строка — одна тема
- пустые строки игнорируются
- строки с `#` не считаются комментариями для тем и могут быть темой

## Плейсхолдеры

Поддерживаются:

- `{{name}}` — имя получателя из CSV, если есть колонка `name`
- `{{email}}` — email получателя
- `{{senderName}}` — имя отправителя из будущего `senders.txt`

Плейсхолдеры регистронезависимые и допускают пробелы внутри скобок, например `{{ name }}`.

## GUI

На вкладке `Content` добавлен блок `Темы писем`:

- кнопка `Загрузить темы`
- счётчик `загружено N тем`
- превью первых 5 строк
- поле тестового email
- поле тестового name
- поле тестового senderName
- кнопка `Сгенерировать пример`
- live-preview результата с подстановкой плейсхолдеров

## Core

`core/content.py`:

- `SubjectManager.load_from_file()`
- `SubjectManager.choose_random()`
- `SubjectManager.render_random()`
- `render_subject()`
- `RecipientContext`

При формировании каждого будущего письма нужно вызывать `SubjectManager.render_random(recipient, sender_name)`, чтобы тема выбиралась случайно из загруженного списка.

## Storage

`core/storage.py` получил параметр `ignore_comments`.

Для прокси/SMTP комментарии `#` продолжают игнорироваться. Для `subjects.txt` комментарии не игнорируются, потому что задача требует пропускать только пустые строки.
