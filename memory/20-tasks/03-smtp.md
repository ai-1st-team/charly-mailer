# Task 03 — SMTP Rotation

## Сделано

Добавлена загрузка SMTP-аккаунтов из файла `smtps.txt`.

Формат строки:

- `host:port:email:password`

Пустые строки и строки, начинающиеся с `#`, игнорируются через общий `core/storage.py`.

Добавлен standalone-скрипт:

- `test_smtp_login.py`
- запуск: `python test_smtp_login.py data/smtps.txt`
- проверяет login без GUI и печатает статусы по аккаунтам

## GUI

На вкладке `Setup` теперь две колонки:

- слева `Прокси`
- справа `SMTP`

В блоке `SMTP`:

- кнопка `Загрузить smtps.txt`
- кнопка `Проверить все`
- список карточек аккаунтов
- в карточке: email, host:port, статус, счётчик отправленных за сессию, режим шифрования, режим прокси, кнопка `Проверить`

Статусы:

- `живой` — зелёный
- `мёртвый` — красный
- `неизвестный` — серый
- `проверка` — жёлтый

Проверки идут в background thread, GUI не должен зависать.

## Core

`core/smtp_manager.py`:

- парсит `host:port:email:password`
- хранит пароль только внутри модели, не выводит в GUI/logs
- определяет шифрование по порту:
  - `465` → SSL
  - `587` → STARTTLS
  - `25` → STARTTLS если сервер поддерживает, иначе без шифрования
- проверяет login через `smtplib`
- ставит timeout на connect/login
- показывает конкретные причины ошибок: auth, timeout, server unavailable, SMTP response
- ведёт session-счётчик отправленных писем
- отдаёт round-robin только по живым аккаунтам
- `prepare_live_rotation()` перед будущей рассылкой перепроверяет аккаунты и возвращает только живые
- 5xx auth-ошибка помечает аккаунт мёртвым
- 4xx временная ошибка не убивает аккаунт автоматически

## Прокси для SMTP

В `SMTPAccount` есть:

- `bound_proxy_url`
- `use_global_proxy_pool`

Менеджер умеет открыть SMTP-соединение через HTTP CONNECT proxy tunnel, если передан конкретный proxy URL. GUI-привязка прокси к аккаунту пока не вынесена в отдельный контрол, её логично добавить вместе с реальной отправкой.

## Логи

События загрузки и проверки пишутся JSON Lines по дням в `logs/YYYY-MM-DD.jsonl`.

## Важно дальше

Когда появится отправка, брать аккаунты через `SMTPManager.get_next_live_account()` и после успешной отправки вызывать `record_send_success()`.
